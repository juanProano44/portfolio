## Contexto

Proyecto freelance construyendo el frontend para una plataforma e-learning. Trabajé directamente con el cliente para traducir diseños de Figma en una aplicación React lista para producción.

## Enfoque

Seguimos un flujo de desarrollo orientado a componentes: empezamos con componentes atómicos, los compusimos en templates y los conectamos a las APIs del backend. Priorizamos accesibilidad y diseño responsivo desde el inicio.

## Contribuciones clave

- Traduje diseños de Figma en componentes React pixel-perfect
- Implementé layouts responsivos para escritorio, tablet y móvil
- Construí componentes UI reutilizables con tipado TypeScript adecuado
- Integré con APIs REST para contenido de cursos y gestión de usuarios
