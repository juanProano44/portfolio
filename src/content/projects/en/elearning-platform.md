## Context

Freelance project building the frontend for an e-learning platform. Worked directly with the client to translate Figma designs into a production-ready React application.

## Approach

Followed a component-driven development workflow: started with atomic components, composed them into templates, and connected them to the backend APIs. Prioritized accessibility and responsive design from the start.

## Key contributions

- Translated Figma designs into pixel-perfect React components
- Implemented responsive layouts for desktop, tablet, and mobile
- Built reusable UI components with proper TypeScript typing
- Integrated with REST APIs for course content and user management
